# School-Network-Subnetted-Server
Secure hierarchical school network simulated in Cisco Packet Tracer featuring classroom isolation via 802.1Q VLANs, VLSM subnetting (/24 &amp; /28), Router-on-a-Stick inter-VLAN routing, and Extended Access Control Lists (ACLs) to enforce role-based traffic policies across students, teachers, and management.
